# Sistema de Biblioteca en Java

Proyecto académico de **Programación** en la **Universidad Tecnológica de Panamá (UTP)**, orientado a la modelación de entidades y gestión básica de un sistema bibliotecario en Java.

## Propósito del proyecto
Practicar la organización modular del código, el manejo de entidades del dominio y la lógica de préstamos y administración dentro de un sistema de biblioteca.

## Estructura del proyecto
* `pom.xml`: Configuración Maven del proyecto.
* `src/main/java/com/prog1/biblioteca/SistemaBiblioteca.java`: Lógica principal de gestión del sistema.
* `src/main/java/com/prog1/biblioteca/Libro.java`: Representación de los libros del catálogo.
* `src/main/java/com/prog1/biblioteca/Usuario.java`: Gestión de datos de usuarios.
* `src/main/java/com/prog1/biblioteca/Bibliotecario.java`: Funciones y operaciones administrativas.
* `src/main/java/com/prog1/biblioteca/Prestamo.java`: Control de préstamos de libros.

## Ejecución
1. Importa el proyecto Maven en tu entorno de desarrollo (Apache NetBeans, VS Code o IntelliJ IDEA).
2. Ejecuta la clase principal correspondiente (`SistemaBiblioteca`).
